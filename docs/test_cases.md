# Тест-кейс TC-01: Создание задачи (успешный сценарий)

- Предусловия: файл данных отсутствует.
- Шаги:
  1. Запустить программу.
  2. Ввести команду: add "Купить молоко" "Завтра".
  3. Ввести команду: list.
- Ожидаемый результат: в списке есть задача "Купить молоко", статус "new".
- Постусловия: файл данных содержит запись о задаче.

# Тест-кейс TC-02: Создание задачи с пустым названием

- Предусловия: файл данных отсутствует.
- Шаги:
  1. Запустить программу.
  2. Ввести команду: add "" "Описание".
- Ожидаемый результат: программа выводит сообщение об ошибке "Название задачи не может быть пустым".
- Постусловия: файл данных не создан или пуст.
