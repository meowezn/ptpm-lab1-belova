# Чек-лист регрессии (CL-REG-01)

1. Запустить программу — нет ошибок при старте.
2. Создать задачу — задача появляется в списке.
3. Изменить статус задачи — статус сохраняется.
4. Сохранить задачи в JSON — файл создаётся.
5. Загрузить задачи после перезапуска — задачи на месте.
6. Поиск по ключевому слову — результат соответствует ожиданиям.
7. Создать задачу с пустым названием — программа сообщает об ошибке.
8. Загрузить повреждённый JSON — программа не падает, сообщает об ошибке.
